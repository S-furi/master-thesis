# Master Thesis

> *Fully-reactive Discrete Event Simulation: from first principles to a working prototype*

University of Bologna Master's Degree final thesis on *reactive programming* used in *Discrete event simulation*. The design
and basis are layed down and its feasibility is demonstrated by implementing a working prototype on
a mature stochastic DES: [Alchemist](https://github.com/AlchemistSimulator/Alchemist).

Raw work can be found at the personal fork and branch: [github.com/S-furi/Alchemist/reactive-engine](https://github.com/S-furi/Alchemist/tree/feat/reactive-engine)
